파일을 페이지별로 분리했다. 홈 진입에 필요한 실행 파일은 약 696KB 합계,
gzip 약 220KB이며, 약 456KB의 문서 엔진과 에디터·관리자 화면은 필요 시 로딩한다.
이 수치는 코드 크기 비교이며 실제 Lighthouse나 모든 네트워크 상황의 로딩 시간 측정은 아니다.

기능 테스트 44개와 실제 Firestore 에뮬레이터 테스트 5개가 통과했다.
