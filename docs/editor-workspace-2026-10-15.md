# 에디터 작업 화면 개선

## 변경 사항

- 왼쪽 초안 사이드바와 과한 본문 여백을 없애 본문 공간을 확보했습니다.
- 저장, 발행, 미리보기, 집중 모드를 상단에 고정했습니다. 실제 상단 높이에 맞춰 서식 도구 위치가 자동 조정됩니다.
- 오른쪽 작업 패널은 블록 설정, 목차, 글 설정, 초안, 이력, 템플릿으로 구분했습니다.
- 작은 화면에서는 작업 패널을 닫을 수 있는 서랍으로 표시하고 서식 도구를 가로 스크롤합니다.
- 목차에서 본문 블록을 검색하고, 해당 위치로 이동하거나 위아래로 재배치할 수 있습니다.
- 이미지와 갤러리를 선택하면 해당 블록 옆에서 크기, 배치와 이미지별 캡션을 편집할 수 있습니다.
- 기사 본문 전체를 실제 기사 컴포넌트와 스타일로 미리 봅니다. 독립된 화면 폭으로 데스크톱과 모바일 배치를 확인합니다.
- 발행 전 제목과 본문은 필수 확인, 대표 이미지, 빈 갤러리, 대체 텍스트, 링크는 권장 사항으로 안내합니다.
- 저장 및 발행과 수정 이력 기록을 같은 트랜잭션으로 처리합니다. 실패하면 모두 보류하고 복구본을 유지합니다.
- 발행된 글을 수정하면 이전 공개 버전도 기록합니다. 서버 기록은 최근 30개를 유지하며 일반 방문자는 읽지 못합니다.
- 이력 복원과 템플릿 적용은 먼저 편집 화면에만 적용합니다. 명시적인 저장 또는 발행 전에는 자동 저장을 보류합니다.
- 적용 전 내용은 기기 백업에 보관하고 다시 복원할 수 있습니다. 전시, 인터뷰, 리뷰 기본 템플릿과 개인 템플릿 저장을 제공합니다.
- 개인 템플릿과 적용 전 백업은 해당 사용자·브라우저에 저장됩니다. 다른 직원이나 기기에 자동 공유되지 않습니다.
- 새 에디터 초기화 중 초안 목록 요청이 무효화되어 빈 목록이 보일 수 있던 문제를 수정했습니다.
- 커서 이동 때 전체 편집 화면이 다시 렌더링되지 않도록 하고 본문 복구 기록은 입력 후 짧게 묶어 기록합니다. 페이지 이탈 시에는 즉시 최신 내용을 보관합니다.
- 에디터 확인창은 브라우저 기본 창 대신 앱 내부 대화상자를 사용합니다.

## 검증

- 자동 테스트 74개, Firestore 에뮬레이터 권한 테스트 6개 통과.
- 코드 검사와 운영 빌드 통과. 테스트 화면과 모의 계정이 운영 빌드에 포함되지 않는 것을 확인했습니다.
- 로컬 브라우저에서 초안 로딩, 저장 및 이력 생성, 개인 템플릿 저장, 기본 템플릿 적용, 발행 필수 항목 차단, 전체 본문 및 모바일 기사 미리보기를 확인했습니다.
- 390px 편집 화면에서 도구 모음의 페이지 가로 넘침을 찾아 수정하고 페이지 폭과 콘텐츠 폭이 일치함을 확인했습니다.
- 검수 브라우저의 기존 기본 확인창이 자동 조작을 막아 이후의 모바일 서랍 조작과 새 앱 내부 확인창의 실제 클릭 검증은 제한되었습니다. 해당 흐름의 저장 보호와 복원은 자동 테스트로 검증했습니다.
- 테스트 콘텐츠는 로컬 에뮬레이터에만 작성했습니다. 실제 운영 글을 시험 발행하지 않았습니다.

## 로컬 재검수

Firestore 에뮬레이터 8085를 실행하고, `VITE_FIREBASE_PROJECT_ID=demo-unframe-mag`로 개발 서버를 실행한 뒤 `/tests/editor-ui.html`을 엽니다.
모의 계정은 개발 모드, 로컬 주소, 테스트 프로젝트에 한해서 실행되며 실제 Firebase 서버에는 연결하지 않습니다.
권한 회귀 테스트는 `FIRESTORE_EMULATOR_HOST=127.0.0.1:8085 node --test tests/firestore.rules.mjs`로 실행합니다.
